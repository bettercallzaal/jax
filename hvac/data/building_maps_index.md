# JAX Building Maps Index

Catalog of the floor-plan / site-map files in `W:\Administrative\Building Maps` (JAX Bar Harbor campus, plus Gainesville, Hemlock Lane apartments, and NYSCF-NYC subfolders). Generated by reading each file's title block and content — not a substitute for the source drawings, but useful for quickly finding "which PDF has building/room X" without opening the share.

174 files cataloged (root folder + `Floor Plans/`, `Hemlock Lane Apts/`, `NYSCF/`).

## Known filename/content mismatches on the source share

While cataloging, several files were found to contain drawings that don't match their filename — worth knowing before trusting a filename alone:

- **01c-1.PDF** actually contains the Unit 3 Level 2 plan (drawing no. 01c-2); **01c-2.PDF** actually contains the Unit 3 Level 1 plan (drawing no. 01c-1). Their content is swapped relative to the filenames.
- **50-G070-080-BethanyDanielsWO.pdf** actually contains the Level Two/interstitial plan (no G070/G080 markup); **50_1i.pdf** actually contains the Level G plan with the G070/G080 highlight that the other filename implies. Content appears swapped between these two files.
- **51-1.pdf** actually contains the Level 2 plan (drawing no. 51-2); **51-2.pdf** actually contains the Level 1 plan (drawing no. 51-1). Content is swapped relative to the filenames.
- **76-3.pdf** (root) and **Hemlock Lane Apts/76-3.pdf** are identical duplicates.
