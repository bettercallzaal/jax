## Business & Operations-Focused Recipes

**Skills & Automation**
- Claude Skills Introduction — create documents, analyze data, automate workflows
  (Excel, PowerPoint, PDF skills)
- Claude Skills for Financial Applications — financial dashboards and portfolio
  analytics
- Building Custom Skills — specialized organizational workflow extensions (this is
  exactly what the HVAC toolkit's skills — dashboard, dat-review, work-order,
  troubleshoot — already are)

**Data & Analytics**
- Data Analyst Agent — turn CSVs into narrative HTML reports with interactive charts
- Slack Data Analyst Bot — mention a bot with a CSV, get analysis in-thread
- Text to SQL — natural language to SQL for database access

**Knowledge Management & Retrieval**
- RAG (Retrieval Augmented Generation) — build/optimize retrieval systems
- Knowledge Graph Construction — from unstructured text
- Contextual Retrieval — improve RAG accuracy with context-enriched chunks

**Agent Patterns for Operations** (most relevant analogues to the HVAC toolkit)
- SRE Incident Response Agent — reads logs, pinpoints root cause, opens fix PRs when
  alerts fire — direct analogue to `troubleshoot` reading Metasys/journal data and
  pinpointing root cause on a comfort complaint
- Threat Intelligence Enrichment Agent — investigates indicators across sources
- Customer Service Agent — chatbot with tools for lookup and order management
- Multi-agent Coordination — specialist teams (researcher, librarian, pricer)
  coordinating on complex tasks

**Memory & Context Management**
- Build Agents That Remember Users — persistent preferences across interactions
- Session Memory Compaction — managing long-running conversations
